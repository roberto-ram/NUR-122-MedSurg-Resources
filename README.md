# NUR 122 Med-Surg Resources

Shared study resources for NUR 122 Medical-Surgical Nursing.

## Contents

- `exams/` — exam study guides, quick references, practice materials, and course resources
- `sources/` — instructor and course reference files
- `resources/Lippincott/` — Lippincott Advisor reference PDFs

## Privacy and access

This repository intentionally excludes patient records, clinical paperwork,
completed assignments, personal reflections, signatures, and temporary working
files. Keep the repository private and grant access only to classmates who are
independently authorized to use the included course and licensed materials.

## Disclaimer

These files are study resources and are not a substitute for course instructions,
clinical policies, or professional medical advice. Respect the copyright and use
terms that apply to each original source.
