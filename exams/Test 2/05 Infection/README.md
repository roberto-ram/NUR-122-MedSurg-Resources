# Infection — Day 11

Study pneumonia, influenza, cellulitis, and MRSA.

Build around: host defense → pathogen/transmission → local and systemic response → diagnostics/cultures → isolation and treatment → gas-exchange or tissue-integrity priorities → sepsis and deterioration cues.

Key comparison: respiratory infection vs skin/soft-tissue infection; colonization vs active MRSA infection.

## Objective-based priorities

- Explain normal host defenses and the response to invading pathogens.
- Recognize assessment and diagnostic findings for pneumonia, influenza, cellulitis, and MRSA.
- Differentiate respiratory from skin/soft-tissue infection, including transmission patterns.
- Select appropriate nursing care and infection-control precautions.
- Evaluate treatment and recognize respiratory decline, spreading infection, or sepsis.
