# Peripheral Perfusion — Day 8

Study PVD, PAD, and chronic venous insufficiency.

Build around: arterial inflow versus venous return → tissue effects → pulse/skin/pain/edema findings → positioning and activity → compression safety → wound risks → evidence of improvement or deterioration.

Key comparison: PAD vs CVI.

## Objective-based priorities

- Explain how arterial and venous systems support systemic circulation.
- Recognize assessment and diagnostic evidence of impaired peripheral perfusion.
- Differentiate PAD from CVI using pain, pulses, skin, edema, ulcers, and positioning clues.
- Select safe nursing interventions for arterial versus venous disease.
- Evaluate treatment response and identify worsening tissue perfusion.
