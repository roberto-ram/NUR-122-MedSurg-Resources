# Test 2 — Active Study Workspace

The course reading list assigns **75 questions, including math calculations**, to Lecture Days 7–12.

## Coverage

1. **Coronary perfusion** — CAD, chronic stable angina, ACS, unstable angina, MI
2. **Peripheral perfusion** — PVD, PAD, chronic venous insufficiency
3. **Heart failure** — congestive heart failure
4. **VTE** — DVT and pulmonary embolism
5. **Infection** — pneumonia, influenza, cellulitis, MRSA
6. **GI inflammation** — GERD, pancreatitis, appendicitis, hepatitis A–E

## Folder guide

- `00 Planning/` — official reading assignments, objectives, and study sequence
- `01 Coronary Perfusion/` through `06 GI Inflammation/` — topic-specific notes and study aids
- `Practice Questions/` — mixed and topic-based exam questions
- `Case Studies/` — progressive clinical-judgment cases
- `Quick References/` — comparison sheets, lab guides, medication tables, and priority cues
- `Workfiles/` — temporary extracts, renders, scripts, and intermediate artifacts

Use the project-level `sources/` directory for synced project references. Newly supplied Test 2 files may be copied into the relevant topic's `Source Materials/` folder so each lecture block stays self-contained. Treat all supplied course documents as read-only reference material.

## Objective-first study rule

Use [`00 Planning/Test 2 Priority Map.md`](00%20Planning/Test%202%20Priority%20Map.md) before studying or creating materials. It converts the official exemplars and objectives into a priority checklist for every lecture. Each lecture folder repeats its applicable checklist so the focus stays visible while working within that topic.
