# Venous Thromboembolism

The official reading list labels VTE as **Lecture Day 10**. The user supplied this file set as **Lecture Day 8** in the current class sequence. Keep the materials grouped by exemplar under VTE regardless of the day number.

Study VTE, DVT, and pulmonary embolism.

Build around: Virchow's triad → venous clot → local obstruction or embolization → DVT versus PE findings → prevention and immediate priorities → anticoagulation monitoring → bleeding and cardiopulmonary complications.

Key comparison: DVT vs PE.

## Objective-based priorities

- Explain venous-clot formation and its effects on perfusion.
- Recognize risk factors, assessment findings, and diagnostics for DVT and PE.
- Differentiate localized DVT from pulmonary embolism.
- Prioritize prevention, safe clot management, and rapid response to suspected PE.
- Evaluate anticoagulation and monitor for bleeding or recurrent embolization.
