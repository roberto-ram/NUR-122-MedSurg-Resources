# Test 1 — Study Workspace

Coverage: Lecture Days 1–6, organized with the same folder style as Test 2. Diabetes spans Days 3–4, so Test 1 has five topic blocks.

## Coverage

1. **Electrolyte Balance — Day 1** — Sodium, potassium, calcium, magnesium, phosphorus, and chloride deficits and excesses.
2. **Acid-Base Balance — Day 2** — Metabolic acidosis, metabolic alkalosis, respiratory acidosis, and respiratory alkalosis.
3. **Diabetes — Days 3–4** — Type 1 and Type 2 diabetes, including hypoglycemia and hyperglycemia in the objectives.
4. **Anemias — Day 5** — Iron deficiency, megaloblastic (pernicious and folic acid), and hemolytic (sickle-cell) anemias.
5. **Perioperative Care — Day 6** — Preoperative preparation and postoperative recovery.

## Objective-first study rule

Start with [00 Planning/Test 1 Priority Map.md](00%20Planning/Test%201%20Priority%20Map.md), then the applicable topic README and official objectives. Original course PDFs remain read-only in the project-level `sources/` folder. Existing study aids support the objectives; they do not replace instructor materials.

This workspace covers NUR 122 only. Separate chemistry-course materials belong in the separate chemistry workspace. Med-Surg electrolytes, acid-base content, and patient laboratory values remain part of NUR 122.
